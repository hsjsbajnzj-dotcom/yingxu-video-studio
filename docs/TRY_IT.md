# 首批试用：先找5位真实用户

这是招募目标，不表示已有5位用户。项目当前为实验性源码预览，无收费、无效果承诺；请先阅读README的来源、第三方条款和验收限制。

## 哪种测试最有帮助

- 没有模型：测试Python3.12安装、网页启动、中文表单和分镜保存/导出。
- 已有兼容本地引擎：在已核对许可和配置的前提下，测试一条5秒短片、取消任务与输出位置。不要为了测试盲目下载全套权重。
- 参与开发：小范围修复中文报错、配置诊断和可复现缺陷，先开Issue说明方案。

## 一次测试清单

- [ ] 网页能打开；诊断能如实显示缺少的依赖。
- [ ] 中文提示词能保存，项目刷新后仍在。
- [ ] 项目导出/导入后，镜头文字和参数一致。
- [ ] 未配置引擎时，没有被误导为模型已安装。
- [ ] 如已配置并实际生成：记录模型、版本、参数和实际耗时，检查输出视频。
- [ ] 没有模型就把生成、取消、画质项目标为“未测”，不要勾选通过。

## 在Issue中反馈

使用[反馈模板](https://github.com/hsjsbajnzj-dotcom/yingxu-video-studio/issues/new?template=first_trial.md)。建议写：

```text
测试版本：
系统 / Python：
CPU / RAM / GPU / VRAM（生成测试才需）：
是否已有本地引擎 / 节点 / 权重及具体版本：
成功走到哪一步：
复现步骤：
预期 / 实际：
实际原生分辨率 / 时长 / 参数 / 耗时 / 后处理（未生成则填未测）：
希望优先改进的一件事：
```

公开Issue不要附API Key、完整电脑路径、私人原片、真实人声音色或未授权人物照片。只提供脱敏错误与最小复现。漏洞不在公开Issue披露，参考SECURITY.md；维护者私报渠道仍待完善。

目前不收集姓名、邮箱、微信和其他联系方式，也没有自动遥测。维护者先按复现价值处理，不承诺回复时限或所有需求均会实现。
