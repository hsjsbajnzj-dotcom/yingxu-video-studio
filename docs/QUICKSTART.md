# 映序快速上手

目标：先打开网页、保存一个分镜项目，再考虑接通视频引擎。不要一开始同时安装所有模型和增强器。

## 1. 下载与检查环境

从[预发布页面](https://github.com/hsjsbajnzj-dotcom/yingxu-video-studio/releases)下载 Source code (zip)，解压到你有写权限的独立文件夹。当前安装器只验收 Python 3.12，先在终端运行 `python --version` 确认；需要Git不是下载ZIP用户的前提。

本包没有视频权重、ComfyUI、WanGP、FFmpeg或CUDA，不要把下载体积误认为全部模型已安装。

## 2. 先装轻量网页

在解压目录打开终端：

```text
python install_web.py
python start_studio.py --doctor
python start_studio.py --no-browser --port 7869
```

访问 http://127.0.0.1:7869/ 。终端需要保持运行；双击HTML不是启动方法。端口冲突就换一个空闲端口。不要绑定公网、开隧道或做端口转发。

安装器创建本目录的独立 `.venv` 和 `config.local.json`，不会替换系统Python或下载模型。再次安装保留本地配置。

## 3. 不装模型也能先试什么

1. 打开“快速生成”，输入一段中文提示词。
2. 点击“加入分镜工作流”，编辑项目名及镜头名，保存。
3. 刷新页面，确认镜头和文字仍在。导出项目后，可在一个新项目中导入检查。
4. 打开“模型与工具”，未配置引擎应显示未配置并禁用入口，这是正常状态。

此过程没有生成视频。不要点击“开始生成”后把缺少引擎的错误理解成电脑坏了。

示例提示词：

> 午后的阳光照在桌面的白瓷杯上，几缕蒸汽缓慢上升，窗外树叶轻轻摆动。固定镜头，5秒、横屏16:9，不新增人物，不加文字或配乐。

## 4. 需要CPU媒体功能时

```text
python install_web.py --media
```

同时自行安装FFmpeg/FFprobe，加入PATH，或在本地配置tools区填写真实路径。媒体诊断就绪不代表GPU视频模型就绪。视频拆镜、帧提取和导出等媒体工具不随基础网页依赖一并具备。

## 5. 接通已有引擎

先备份自己的引擎配置。参考config.example.json，在本地config.local.json的engines区填写真实root、独立python路径和port。Windows JSON路径使用正斜杠，或将反斜杠写成双反斜杠。

- ComfyUI root包含main.py；base_directory要与自己的节点安装布局一致。还需要适配节点及对应权重，不能只填路径就保证出片。
- WanGP当前入口适配root/app/wgp.py结构，其他目录布局可能不支持。它是外部工作台入口，不能由此推断所有模型都已接入快速表单。
- 网页 `.venv` 不是引擎的GPU环境。模型/输入/输出目录需与配置和节点实际布局匹配。
- 高级增强与声音组件默认关闭。核对各自许可、依赖和模型后再单独验证，不要一次全开。

当前没有经过完整新机器与GPU验收的一键模型安装教程。H3/WanGP相关条款边界尚待最终核查，不能承诺所有地区、用途或服务形态都适用。云端API需自行配置与付费，不等于App免费额度。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| Python版本不支持 | 安装器要求3.12，不会替换系统Python |
| 网页打不开 | 启动终端是否仍在、端口是否冲突、是否用127.0.0.1访问 |
| 引擎显示未配置 | 本地JSON路径、独立Python及main.py/app/wgp.py是否存在 |
| FFprobe缺失 | FFmpeg工具安装/PATH或tools配置；不需要先加内存条 |
| 节点或权重找不到 | 外部引擎自己的节点及模型版本；本项目不附带这些资源 |
| 人脸变形、画质不佳 | 记录底层模型和参数，做短片测试；不是安装网页即可提高画质 |

反馈前请阅读[试用清单](TRY_IT.md)与[安全说明](../SECURITY.md)。
